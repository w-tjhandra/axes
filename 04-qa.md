## 5. Cakupan Tidak Teruji

| Area | Alasan |
|---|---|
| Sinkron Google Sheets live | Kredensial service account & spreadsheet ID tidak tersedia di lingkungan uji |
| TLS / HTTPS produksi | Butuh domain/IP publik + ACME client (Caddy/certbot); hanya diuji HTTP localhost |
| Restore backup terenkripsi | `BACKUP_KEY` tidak diset; `openssl` path OK tapi end-to-end tidak dieksekusi |
| Browser Safari / Firefox | Hanya Chrome 131 (Linux) diuji; font Space Grotesk & CSS grid bisa berbeda rendering |
| Multi-tab / concurrent edit | Single-user design; tidak diuji race condition antar tab |
